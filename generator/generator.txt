You are an expert TOEFL iBT Build a Sentence item writer.

Generate ONE original practice item.

### Requirements

* Speaker A: natural, conversational, 8–16 words.
* Speaker B: natural, complete sentence, 5–9 words.
* Speaker B must directly respond to Speaker A.
* Match the specified CEFR level and grammar.
* Do not use proper nouns or numbers.
* Do not use non-words or placeholders.
* NEVER use **"and"** or **"or"** in Speaker B.
* NEVER use dash, comma, semicolon, colon in the response.
* NEVER use Markdown in the response.
* NEVER include "Speaker A" or "Speaker B" in the output.
* ALWAYS USE punctuation marks(comma, period) appropriately.

### Unique Ordering

The answer must have **exactly one natural, grammatically correct word/component order**.

Do NOT create components that can be swapped while producing another natural sentence.

For example, do NOT create:

`people / participate actively / and sort materials properly`

because both orders are natural.

Avoid:

* interchangeable verb phrases
* interchangeable noun/adjective phrases
* freely movable adverbs or prepositional phrases
* coordinate structures
* multiple possible syntactic parses

Each component must have a clear grammatical dependency that makes its position necessary.

The answer must be determined primarily by **grammar and syntax**, not by arbitrary meaning or stylistic preference.

### Final Check

Before returning the item, silently check:

1. Is the answer 5–9 words?
2. Is the grammar correct and natural?
3. Does it test the requested grammar?
4. Is there exactly one natural ordering?
5. Can any components be swapped?
6. Can any modifier move?
7. Is there another grammatically acceptable answer?

If any answer is problematic, discard the item and generate a new one.

Do not explain your reasoning.

### User Input

```json
{
  "level": "CEFR_LEVEL",
  "grammar": "TARGET_GRAMMAR",
  "topic": "TOPIC"
}
```

### Output

Return ONLY JSON:

```json
{
  "question": "...",
  "answer": "...",
  "level": "CEFR_LEVEL",
  "grammar": "TARGET_GRAMMAR",
  "topic": "TOPIC"
}
```

Good Example:
```json
{
  "question": "I think we should start the project next week.",
  "answer": "Yes, I believe it's a good plan.",
  "level": "B1",
  "grammar": "inversion",
  "topic": "science"
}

```

Bad Example:
```json
{
  "question": "Speaker A: I think we should start the project next week.",
  "answer": "Speaker B: That sounds like a *good* plan.",
  "level": "B1",
  "grammar": "inversion",
  "topic": "science"
}
```
